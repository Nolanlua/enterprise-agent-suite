# 运维手册

## 1. SLO

| 服务 | 指标 | 目标 |
|---|---|---|
| 岐黄智库 | 可用性 | 99.9% |
| 岐黄智库 | P95 延迟 | 小于 3 秒 |
| 零售 Agent | 可用性 | 99.9% |
| 零售 Agent | P95 延迟 | 小于 2 秒 |
| 订单服务 | 下单成功率 | 大于 99.5% |
| 数据中台 | 特征新鲜度 | 小于 72 小时 |

## 2. 监控

- 请求量、错误率、P95/P99；
- LLM token 成本和超时；
- 检索命中数、Rerank 耗时；
- 引用校验失败率；
- 安全拦截率；
- 特征缺失率；
- 订单幂等命中率、供应商错误率；
- Outbox 积压。

## 3. 告警

- 5 分钟错误率超过 2%；
- P95 超过 SLO；
- 安全拦截率异常下降；
- 评测通过率低于门禁；
- 特征缺失率超过 5%；
- Outbox 积压超过 1000 条；
- 供应商 5xx 连续 3 分钟。

## 4. 常见故障

### LLM 超时

1. 检查模型服务状态；
2. 降级到模板/抽取式回答；
3. 熔断 1 分钟；
4. 记录请求 ID 和用户影响。

### 向量库不可用

1. 降级到 BM25；
2. 如果 BM25 也不可用，返回“暂时无法检索”；
3. 不返回无依据答案。

### 特征过期

1. 数据中台返回 404；
2. Agent 返回“数据未同步”，不计算；
3. 检查 Airflow DAG 和上游数据。

### 订单重复

1. 检查 Idempotency-Key 是否一致；
2. 查 idempotency_keys 表；
3. 检查唯一索引是否存在；
4. 供应商侧对账。

## 5. 发布

- 数据迁移先于服务发布；
- 评测门禁通过才允许合并；
- 灰度 10% 流量，观察错误率、P95、安全指标；
- 回滚使用上一镜像和上一数据版本；
- 评测集版本随代码版本记录。

## 6. 本地运行

~~~bash
cp .env.example .env
make bootstrap
make infra-up
make data
~~~

每个服务单独启动，详见 README。
