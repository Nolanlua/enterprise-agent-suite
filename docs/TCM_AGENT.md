# 岐黄智库 · 中医药知识库 Agent

## 1. 业务目标

面向中医药从业者、门店健康顾问和培训人员，提供：

- 中药材功效、性味、归经、禁忌的检索；
- 方剂组成、功用、主治的检索；
- 经典著作的背景和原文导读；
- 指南和规范的检索；
- 带出处的回答和安全提示。

明确不做：

- 在线诊断；
- 处方开具；
- 剂量调整；
- 替代执业医师。

## 2. 数据

数据中台提供：

- documents.jsonl：doc_id、title、category、source、dynasty、content、herbs、formulas、contraindications；
- 文档分块后写入 Qdrant 和 OpenSearch；
- 药材、方剂、经典实体写入 Neo4j；
- 质量规则保证必填字段、长度、重复、禁忌字段。

## 3. 工作流

~~~text
classify → normalize → retrieve → graph_expand → safety_precheck
         → generate → verify → finalize
~~~

### classify

规则优先：方剂、经典、指南、药材、症状、通用。规则可解释，成本低。

### normalize

把口语映射到规范术语，例如“上火”到“热证”，“拉肚子”到“泄泻”。保留原问题作为一路检索，避免改写漂移。

### retrieve

- OpenSearch BM25：药材名、方剂名、经典名；
- Qdrant 向量：自然语言、近义表达；
- RRF 融合；
- 可选 Rerank。

### graph_expand

Neo4j 查实体关系，例如药材与方剂、方剂与证候。图关系只作为背景，不作为直接引用证据。

### safety_precheck

- 急危重症：直接转急诊，不生成；
- 处方/剂量/特殊人群：拒绝生成诊疗建议；
- 普通问题：继续。

### generate

只使用检索上下文和工具结果，要求 [n] 引用。

### verify

- 引用编号越界检查；
- 禁用断言检查；
- 失败重试一次，再失败走保守兜底。

### finalize

追加免责声明，返回引用和 trace。

## 4. 引用设计

代码按检索顺序生成 [1] 到 [n]，模型只负责使用编号。生成后校验：

- 没有引用：不通过；
- 引用编号越界：不通过；
- 引用资料与回答无关：需要人工或 Judge 复核。

## 5. 安全边界

必须拦截：

- 胸痛、呼吸困难、昏迷、抽搐、大出血等急症；
- 孕妇、儿童、肝肾功能异常等特殊人群的处方请求；
- 要求开方、剂量、加量、长期服用的请求；
- 宣称“包治百病”“保证治愈”“无需就医”的回答。

安全规则在代码里，不依赖模型自觉。

## 6. 评测

- 引用准确率；
- 拒答正确率；
- 安全性；
- 忠实度；
- 人工抽检。

## 7. 已知限制

1. 模拟语料不是权威医学数据；
2. 图谱覆盖有限，不能替代教材和指南；
3. 没有真实医生在线复核流程；
4. 多轮对话目前依赖图状态，生产应接 PostgreSQL checkpointer；
5. 中文分词、OCR 和版面分析需要继续完善。
