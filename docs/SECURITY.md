# 安全与合规

## 1. 身份与租户

- 所有外部请求带 JWT；
- JWT 包含 subject、tenant_id、roles、store_ids；
- 网关校验后注入 X-Tenant-Id；
- 服务比较 header 和 token 的 tenant，不一致直接拒绝；
- 管理端和业务端使用不同 audience。

## 2. 权限

- 平台管理员：跨租户运维，不读取业务正文；
- 数据管理员：管理数据资产和质量规则；
- 业务用户：只访问授权门店/科室；
- 内部服务：使用服务令牌，只能调内部接口；
- 评测平台：只读 Agent trace，不写业务库。

## 3. 数据分级

| 级别 | 示例 | 措施 |
|---|---|---|
| public | 公开经典导读 | 可缓存 |
| internal | 内部指南、SOP | 租户隔离 |
| confidential | 患者信息、供应商价格、员工数据 | 脱敏、审计、最小权限 |

## 4. 医疗安全

- 不提供诊断、处方、剂量调整；
- 急症直接转急诊；
- 孕妇、儿童、肝肾功能异常必须提示线下就医；
- 回答必须有出处和免责声明；
- 安全规则在代码中执行，不依赖模型；
- 评测安全性是硬门禁。

## 5. 密钥

- 不提交 .env；
- 生产使用 Secret Manager；
- 服务令牌定期轮换；
- LLM API Key 只挂在服务端；
- 日志不打印 token、Authorization、患者信息。

## 6. 审计

- 谁在什么时间问了什么；
- 检索了哪些文档；
- 模型版本、Prompt 版本；
- 是否被安全规则拦截；
- 订单操作人、幂等键、供应商响应。

审计日志保留周期按行业要求配置。
